### 3-STEP이 성립하는 조건

- 세 제품은 **스케일러 → 샴푸 → 트리트먼트** 순서로 한 번의 세정에서 이어짐
- 스케일러가 주 1~2회이므로, 세 제품이 모두 쓰이는 날은 **스케일링 하는 날** 하루
- 다만 기획안에 "단계별 시너지 시험 결과에 따라 3-Step 구조의 성립 여부가 결정됨"으로 명시
- 따라서 **순서는 보여주되 시너지는 주장하지 않는다**가 이번 캠페인의 전제

| 카올린·식물성 LPP 사용 | 공식 사용법 (젖은/마른 두피, 방치 시간) |
| 실리콘 프리 | 전 임상 수치 — 전부 목표치, 측정 후 확정 |
| 출시 시점과 채널 | 탈모증상완화 기능성 보고 일정 |

### 스케일러 — 미결

- 상위 3개 제품(솔랩 아쿠아픽, 닥터포헤어 씨솔트, 그로우어스 씨솔트) 리뷰에서는 `coolness` 662건, `bubble` 357건, `massage` 145건, `clean` 113건 확인
- 그러나 올리브영 **두피용 제품 분류는 해당 기간 카테고리 집계 없음**
- 제품 단위로는 잡히고 카테고리 단위로는 없는 상태. 어느 기준을 쓸지 확정 필요
- `bubble` 357건은 기준 제품 셋 중 둘이 **씨솔트(거품 내는 제품)**라서 나온 수치. 우리 제품에 그대로 적용 불가

### 우리가 실제로 경쟁하는 가격대

- 우리 샴푸는 19,800원 / 500ml
- 기획안 벤치마크(어노브 26,800원 · 닥터포헤어 27,900원 · 아로마티카 22,000원)는 대부분 그 위 구간
- **2만원 이하가 샴푸 카테고리 제품 수의 45.3%** — 주변부가 아니라 하나의 큰 축
- 이 구간의 실제 경쟁자는 **려 루트젠 · 헤드앤숄더**. 기획안 비교표에 없는 이름들

**2만원 이하 상위 제품에서 반복되는 언어**

| 축 | 표현 |
|---|---|
| 거품 | `bubble` |
| 청량감 | `coolness` `cooling` |
| 세정력 | `cleansing_power` |
| 볼륨감 | `volume` `voluminous` |
| **가격 가치** | `affordable` `bang_for_buck` |
| 만족·재구매 | `satisfaction` `repurchase` `recommend` |

- 3만원대 벤치마크와 달리 이 구간은 **제형의 고급스러움보다 즉시 체감되는 기본 성능과 가격 가치**가 앞섬
- `affordable`은 헤드앤숄더 두 제품에서 264건·153건. 지금 우리 브리프에 이 축이 아예 없음

- 청량감은 2만원 이하에서 17,944건, 2만~5만원에서 8,240건 — **저가 구간의 언어**
- 거품은 2만원 이하 39,202건, 2만~5만원 52,787건 — **가격대 전반의 기본 기대치**
- 다만 2만원 이하에서 `bubble`을 쓰는 제품이 205개, `coolness`가 103개
- 즉 **거품과 청량감은 차별점이 아니라 자격 요건**. 차별점은 성분(클레이 37개)에서 나와야 함

### 부정 리뷰에서 반복되는 것

- 2만원 이하 상위 3개 제품 기준. **언급량이 2~7건으로 매우 적어 순위를 매기면 안 됨**
- 리뷰 원문은 데이터에 없음. 키워드와 언급량까지만 확인 가능
- 따라서 소구가 아니라 **무너지는 지점을 확인하는 체크리스트**로만 사용

| Objection | 확인할 것 |
|---|---|
| 가려움 `itchy` · 자극 `irritating` | 시원한데 자극적이거나 가렵지는 않은가 |
| 기름짐 `greasiness` · 지성 `oily_skin` | 두피 유분이 충분히 씻겼는가 |
| 거품 `bubble` | 거품의 양과 퍼짐성이 기대에 맞는가 |
| 세정력 `cleansing_power` | 헹군 후 세정감이 부족하거나 과하지 않은가 |
| 냄새 `odor` | 향이 사용 중·사용 후 부담스럽지 않은가 |
| 비듬 `dandruff` | 비듬·각질 고민이 사용 후에도 남는가 |
| 뻣뻣함 `stiff` | 모발이 뻣뻣해지거나 엉키지 않는가 |
| 트러블 `breakout` `acne` | 두피나 헤어라인에 반응이 생기지 않는가 |

- `dandruff`는 헤드앤숄더에서 특히 높음(7건·2건). 비듬 케어를 기대하고 샀다가 실망한 신호
- 우리는 비듬을 소구하지 않으므로 이 실망을 물려받지 않음

### 분석 범위와 한계

- 가격대·Objection·월별 추이는 **2025.09–2026.08** 집계. **2026년 7–8월은 리뷰 0건**

- 두피용 제품 카테고리는 랭킹 집계가 없어 스케일러만 동일 분석 불가

## 3. 이 데이터로 내린 결정

| 결정 | 근거 |
|---|---|
| **테마를 SUNDAY 3-STEP으로 잡는다** | 세 제품이 모두 쓰이는 날은 스케일링 하는 날 하루. 제품이 셋이라 제품별 테마를 따로 잡으면 캠페인이 흩어짐 |
| **게시일을 일요일로 고정한다** | 20개 영상이 같은 날 노출됨. 독촉이 "이번 주 일요일"이라는 한 줄로 끝나 운영 비용도 줄어듦 |
| **크리에이터 1인당 제품 1개, 시간대 릴레이** | 영상 하나에 제품 셋을 넣으면 메시지가 무너짐. 오전 스케일러 · 오후 샴푸 · 저녁 트리트먼트로 하루에 루틴 한 바퀴 |
| **공통 필수 장면을 세정 순서로 정의한다** | 세 제품이 전부 "덜고 → 바르고 → 헹구고 → 결과" 구조. 공통 장면 하나로 세 제품을 묶을 수 있음 |
| **통일 요소는 소품이 아니라 촬영 조건으로 건다** | 두피 제품이라 머리에 착용물을 쓸 수 없음. ASMR(배경음악 없음) · 어깨 타월 · 보정 없음 세 조건으로 대체 |
| **ASMR을 포맷으로 지정한다** | 세 제형이 전부 소리가 남 — 머드의 미세 거품, 고밀도 거품, 멜팅 밤. 소리로 캠페인을 식별시킬 수 있음 |
| **미검증 주장을 전면 차단하고 사유를 적는다** | 임상이 전부 목표치 단계. 사유(시험 예정/목표치/보고 검토)를 함께 적어야 시험 완료 후 무엇이 풀리는지 관리됨 |
| **제품별 고유 키워드를 나눈다** | 세 크리에이터가 같은 말만 하면 제품이 구분되지 않음. 마사지·거품·모발결이 각자의 자리를 잡음 |
| **거품감을 스케일러 키워드에서 뺀다** | 기준 제품이 씨솔트라 나온 수치. 우리 제형은 물에 닿을 때만 미세 거품이 남 |
| **샴푸에서 거품을 핵심 소구로 남긴다** | 거품이 두 집계 모두 1위. 딥클렌징이면서 거품을 지킨 것이 아로마티카(거품 부족 10%) 대비 차별점 |
| **샴푸 메시지 순서를 거품 → 세정감 → 청량감 → 볼륨·모발로 잡는다** | 1월 기준 거품이 청량감의 두 배. 청량감을 앞세우면 비수기 언어를 선두에 두는 셈 |
| **가격 가치를 샴푸 축에 추가한다** | `affordable`이 2만원 이하 상위 제품에서 264건·153건. 19,800원 / 500ml는 실제 경쟁 구간에서 유효한 소구 |
| **경쟁 벤치마크를 2만원 이하로 다시 잡는다** | 기획안 비교 대상은 22,000~27,900원. 실제 경쟁자는 려·헤드앤숄더이고, 2만원 이하가 카테고리 제품 수의 45.3% |
| **거품·청량감을 차별점이 아니라 자격 요건으로 다룬다** | 2만원 이하에서 `bubble` 205개 제품, `coolness` 103개 제품이 이미 사용. 차별점은 카올린(클레이 37개) |
| **부정 키워드를 크리에이터에게 말하게 하지 않는다** | 부정 언급량이 2~7건으로 순위를 매길 수 없음. 필수 언급이 아니라 내부 확인 항목 |
| **CTA를 "댓글에 두피 타입"으로 한다** | 댓글창이 그대로 두피 타입 데이터가 됨. 세 제품 모두에 동일하게 적용 가능 |
| **기한·링크·코드·사용권을 본문에서 DB로 내린다** | 크리에이터 브리프가 길어지면 게시율이 떨어짐. 공통 페이지는 창작 컨텍스트만 |

## 4. 제품별로 만들 콘텐츠

### 스케일러 — SCALE-DOWN

- **겨냥하는 불만** 소금 입자 따가움(그로우어스 22%) · 헹궈도 남는 알갱이 · 스케일링 후 모발 뻣뻣함(닥터포헤어 18%)
- **필수 장면** 머드 제형 클로즈업 · 광폭 노즐 도포 · 손끝 마사지 · 물 닿을 때 미세 거품 · 편집 없는 헹굼 · 헹군 뒤 두피와 모발
- **고유 키워드** `마사지` `잔여물`
- **공통 키워드** `시원함` `쿨링감` `깨끗함` `세정력`
- **검증할 가설** 소금 스케일러 경험자가 클레이 제형을 보고 대체 의향을 보이는가

### 샴푸 — CLEANSE-DOWN

- **메시지 순서** 거품 → 세정감 → 청량감 → 말린 뒤 볼륨·모발 → 가격 가치
- **겨냥하는 불만** 오후 떡짐(어노브 15%) · 거품 부족(아로마티카 10%) · 세정 후 모발 뻣뻣함
- **필수 장면** 적은 양으로 거품 내는 과정 · 두피에서 퍼지는 거품 · 손끝 세정 · 헹굼 · 말린 뒤 뿌리
- **고유 키워드** `거품` `볼륨감` `가격 가치`
- **공통 키워드** `세정력` `시원함` `부드러움`
- **내부 확인 항목** 가려움 · 자극 · 기름짐 · 향 부담 · 세정력 부족·과도 · 비듬 잔존 · 뻣뻣함 · 트러블
- **검증할 가설** 19,800원 구간에서 "거품을 지킨 딥클렌징"이 려·헤드앤숄더 대비 구분되는가

### 트리트먼트 — PROTEIN-FILL

- **겨냥하는 불만** 미끌거리는 잔여감(어노브 18%) · 무거운 영양감(피노 14%) · 지속력 부족(쿤달 9%)
- **필수 장면** 멜팅 밤이 손에서 녹는 과정 · 젖은 모발 도포 · 헹굼 중 손가락 빗질 · 말린 뒤 모발결
- **고유 키워드** `모발결` `윤기` `영양감`
- **공통 키워드** `부드러움` `제형`
- **검증할 가설** 실리콘 없이도 부드럽다는 메시지가 단백질 일변도 시장에서 구분되는가

### 공통으로 확인할 것

- **고농축 멜팅 밤** — 손에서 녹아 모발에 펴집니다
- **샴푸와 같은 계열 향** — 같이 써도 향이 부딪히지 않습니다
