### Mandatory Scenes

세 제품 모두 공통입니다. 순서·길이·대사는 자유이고, 아래가 화면에서 **식별 가능하게** 나오기만 하면 됩니다.

- **제형을 덜어서 보여주는 모습**
  - 손이나 투명한 표면 위에. 색, 점도가 보이도록 천천히
- **바르고 문지르는 모습**
  - 손끝으로. 손톱으로 긁는 연출은 하지 말아주세요
- **실제로 헹구는 모습**
  - 편집 최소화. 남는지 여부가 보이게
- **씻고 난 두피와 모발**
  - 젖은 모발 손가락 빗질, 가능하면 말린 뒤까지
- **본인 이야기 두 번**
  - 왜 써봤는지 / 어땠는지. "제 두피에서는" 처럼

**말할 때만 찍으면 되는 장면**

| 이렇게 말한다면 | 이 화면이 필요합니다 |
|---|---|
| "헹굼이 편하다" | 편집 안 한 헹굼 컷 |
| "잔여물이 없다" | 헹군 뒤 손으로 두피를 훑는 컷 |
| "모발이 부드럽다" | 젖은 상태 + 말린 뒤 손가락 빗질 |
| "거품이 잘 난다" | 적은 양으로 거품 내는 컷 |
| "시원하다" | 언제부터, 얼마나 시원한지 말하는 컷 |
| "자극이 없다" · "무자극" | 시험 진행 중이라 지금은 쓰지 않습니다 |

# 문서 2 — 제품 가이드 · 두피 스케일러

> **루트랩 카올린 퓨리파잉 두피 스케일러** · 200ml / 24,000원 · 2027년 1월 출시

**제품 이미지** — 불투명 튜브, 플립 캡, 광폭 노즐 (입력 필요)

### ROOTLAB 브랜드 소개

**ROOTLAB**은 스킨케어 성분을 헤어케어에 접목한 **스칼프-바이오 브랜드**입니다.
두피 저자극과 쿨링에서 출발해, 이번에 모발까지 케어 범위를 넓혔습니다.

**브랜드가 지키는 것**

- **두피도 피부다** — 얼굴에 쓰는 기준을 두피에 적용
- **실리콘으로 덮지 않는다** — 코팅이 아니라 채우는 방식
- **긁어내지 않는다** — 소금·스크럽 입자 없이

### 이 제품을 고르는 이유

소금으로 긁는 스케일러가 아닙니다.

- **소금·스크럽 입자가 아예 없습니다** — 카올린 클레이가 대신합니다
- **물에 녹습니다** — 헹구고 나서 알갱이가 남지 않습니다
- **광폭 노즐로 두피에 직접** — 머리카락에 묻히지 않고 가르마 사이로
- **주 1~2회** — 매일 쓰는 샴푸가 닿지 않는 구간을 따로

### 뭐가 들었나?

| 성분 | 무슨 일을 하나 |
|---|---|
| **카올린 클레이** | 입자가 고운 흰 진흙. 과잉 유분만 골라서 붙잡습니다 |
| **멘톨 · 페퍼민트 추출물** | 바르는 동안 시원한 느낌을 냅니다 |
| **식물성 LPP 단백질** | 저분자 단백질. 스케일링 후 모발이 뻣뻣해지지 않게 |
| **수용성 머드 베이스** | 물에 닿으면 미세 거품이 나면서 풀립니다 |

**제형** 소프트 머드 크림 · **향** 은은한 허브 계열 · **실리콘 프리**

### 어떻게 쓰나?

- **마른 두피에** — 샴푸 전, 머리를 적시지 않은 상태로
- 광폭 노즐로 가르마를 나눠가며 두피에 바르기
- 손끝으로 3분 마사지
- 물을 적시면 미세 거품이 올라옵니다. 한 번 더 마사지
- 헹구고 나서 샴푸. 끝 🚿

### 이건 꼭 확인해 주세요

**짤 때**

- 은은한 허브 향
- 소프트 머드 제형 — 색, 점도
- 입자가 느껴지는지

**바를 때**

- 광폭 노즐 — 원하는 만큼, 원하는 자리에 나오는지

**마사지할 때**

- 마사지감
- 물 닿았을 때 미세 거품이 올라오는지
- 청량감 — 언제부터, 얼마나

**씻고 나서**

- 헹굼감
- 알갱이가 남는지
- 두피 상태
- 모발이 뻣뻣한지

**이 제품만의 말** `마사지` `잔여물`

**같이 쓰는 말** `시원함` `쿨링감` `깨끗함` `세정력`
