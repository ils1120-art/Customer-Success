### ✿ 이 브리프로 내리는 결정

1. **무엇을 말할 것인가** — 효능이 아닌 **사용감**을 주력 메시지로 확정할지
2. **누구를 캐스팅할 것인가** — 미감 중심 크리에이터가 아닌 **자기 피부를 설명할 수 있는 사람**으로 확정할지
3. **무엇을 말하지 않을 것인가** — 민감·트러블·지속력 표현을 캠페인 전체에서 금지할지
4. **무엇으로 이겼다고 할 것인가** — 조회수 기준과 전환 기준이 갈릴 때 전환을 따를지

### ✿ 배경

- 소비자가 이 제품을 설명할 때 쓰는 말은 효능 용어가 아닌 **사용감 표현** — 촉촉하다 · 광이 난다 · 스며든다 · 가볍다
- 건조함을 말하는 사용자와 유분감을 말하는 사용자가 동일 제품을 사용 중
- 뷰티 콘텐츠 대표 반박 "내 피부엔 안 맞을 것 같은데"가 이미 제품 사용자 내부에 존재
- 효과를 강하게 주장한 영역에 실망 반응 집중 → 주장 강도와 리스크 비례
- 결론: 반박을 숨기지 않고 캠페인 중심에 배치

### ✿ 콘텐츠 컨셉 — 5종

| 컨셉 | 한 줄 씬 | 0–3초 화면 자막 |
|---|---|---|
| **① 스며들고 남는 광채** | 제형을 펴 바르는 순간부터 마무리까지 한 화면 근접 | `GLOW. LIGHT WEIGHT. SMOOTH.` |
| **② 건성·지성 반반 사용기** | 건조함을 말하는 사용자와 유분감을 말하는 사용자가 각자 사용 후 나란히 기록 | `DRY? OILY? HYDRATE. GLOW.` |
| **③ 메이크업 피부의 가벼운 광채** | 평소 메이크업하는 사용자가 사용 장면과 완성된 피부 표면을 근접 촬영 | `MAKEUP. SMOOTH. GLOW.` |
| **④ 선스크린 루틴 속 광채** | 선스크린 루틴 안에서 본 제품을 함께 사용하는 장면 | `SUNSCREEN. HYDRATE. GLOW.` |
| **⑤ 민감 피부 반응 기록** | 민감함을 말하는 사용자가 도포 후 느낀 점을 솔직하게 기록 | 자막 없음 — 조용히 기록 |

> **훅 자막 표기 규칙** — 화면 자막은 단어 나열 형태로만 사용. **따옴표를 붙여 인용문처럼 제시 금지**

**① 스며들고 남는 광채** *(메인)*
- **3–8초**: 제형의 흐름 → 펴 바르는 과정 → 피부 표면을 연속 촬영. 효능 전후가 아닌 실제 사용 장면
- **8–12초 의심 대응**: "무겁거나 기름지지 않나요?" → 도포 직후 피부를 옆에서 비추며 *일부 리뷰어는 light_weight, absorb라고 표현했다* 자막
- **마무리**: 무문구 엔딩. 재구매·추천 멘트 미작성

**② 건성·지성 반반 사용기**
- **3–8초**: 두 출연자가 자신의 피부 상태를 밝힌 뒤, 같은 조명에서 제형과 마무리를 각각 노출
- **8–12초 의심 대응**: "건조하게 느껴지지 않나요?" → 두 사람의 개별 소감 분리 노출 + *일부 리뷰에는 dry, 다른 리뷰에는 hydrate* 자막
- **주의**: 두 사람의 결과를 억지로 같게 만들지 않음
- **CTA**: 피부 타입이 반대인 친구 태그

**③ 메이크업 피부의 가벼운 광채**
- **3–8초**: 제품 사용 장면과 메이크업한 피부의 질감·광택을 자연광·실내광에서 노출
- **8–12초 의심 대응**: "메이크업과 같이 써도 되나요?" → 메이크업 장면 직전 *사용 맥락은 확인됐으나 순서·밀림 방지는 미확인* 자막
- **금지**: 화장 전 사용, 밀림 방지, 지속력 주장

**④ 선스크린 루틴 속 광채**
- **3–8초**: 두 제품이 루틴에 등장하는 모습과 완성된 피부 표면. 도포 순서를 사용법처럼 단정하지 않음
- **8–12초 의심 대응**: "선스크린과 같이 써도 되나요?" → 두 제품 등장 순간 *사용 맥락은 확인됐으나 궁합·밀림 방지는 미확인* 자막
- **금지**: 궁합 보장

**⑤ 민감 피부 반응 기록**
- **3–8초**: 도포 후 느낀 점을 솔직하게 기록
- **필수**: 불편할 경우 **사용을 중단하는 모습** 포함 + 개인차 고지
- **금지**: 안전성 실험처럼 연출
- **평가**: 조회수 기준 제외. 반박 댓글 비율 변화로 판정

### ✿ 이 캠페인에서 검증할 것

1. **사용감 메시지가 효능 메시지보다 전환에 유리한가** — 효능 주장 최소화 상태에서 Amazon 세션·구매 이동 여부
2. **반박 선제 제시 구조가 작동하는가** — 컨셉 ② 댓글에서 "내 피부엔" 류 질문이 타 컨셉 대비 감소하는지
3. **2인 포맷이 확산에 기여하는가** — 컨셉 ②의 공유·태그 수가 1인 포맷 대비 높은지
4. **기록형 콘텐츠가 반박 비율을 낮추는가** — 컨셉 ⑤ 발행 이후 반박 댓글 비율 변화
5. **플랫폼별 위닝 컨셉이 갈리는가** — TikTok과 Instagram 상위 컨셉 상이 여부

### ✿ 캠페인 종료 후

1. **Winning Message Framework** — 위닝 컨셉의 훅·장면 구조 정리, 차기 제품 재사용 가능 형태로 보관
2. **Winning Creator Pool** — 고성과 크리에이터 재계약 대상 등록. 선별 기준은 팔로워 수가 아닌 조회수/팔로워 배수 + 댓글 제품 집중도
3. **Spark Ads** — 저장률 상위 콘텐츠 광고 소재 전환
4. **상세페이지 반영** — 위닝 컨셉 장면을 Amazon A+ 이미지로 이식
5. **차기 라운드** — 탈락 컨셉은 훅만 유지, 다른 증거와 재조합
