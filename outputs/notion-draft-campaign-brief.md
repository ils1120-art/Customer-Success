### ✿ 배경

- 미국 리뷰에서 이 제품을 설명할 때 가장 많이 나온 말은 **촉촉하다 · 광이 난다 · 스며든다 · 가볍다**였음. 효능 용어가 아니라 전부 바를 때의 느낌
- 동시에 **건조함을 말하는 사용자와 유분감을 말하는 사용자가 같은 브랜드 리뷰에 공존**. 뷰티 콘텐츠의 가장 흔한 반박인 "내 피부엔 안 맞을 텐데"가 이미 사용자 안에 있다는 뜻
- 효과를 세게 약속한 쪽에는 실망 리뷰가 붙어 있어, **약속을 늘릴수록 리스크가 커지는 구조**
- 따라서 반박을 숨기는 대신 콘텐츠의 주인공으로 삼는 방향이 필요했음

### ✿ 콘텐츠 컨셉 — 테스트할 4종

> 하나로 정하지 않고 4개를 동시에 발행해 위닝 컨셉을 찾는다. 판정 기준은 아래 성과 측정 설계 참조.

| 컨셉 | 콘셉트 요약 | 키 메시지 | 콘텐츠에서 보여줄 핵심 |
| --- | --- | --- | --- |
| **A. Same Bottle** | 피부 타입이 반대인 두 사람이 한 병을 나눠 씀 | `#SameBottleDifferentSkin` `#MorningGlow` | 병을 건네는 손 / 각자의 피부 선언 / 같은 조명 두 얼굴 |
| **B. The Handoff** | 선스크린과 메이크업 사이, 이 병이 지나가는 자리 | `#BeforeSunscreen` `#UnderMakeup` | 루틴 속도 조절 / 메이크업한 피부 표면 |
| **C. Bare Minute** | 맨얼굴에서 시작해 딱 한 병만 | `#BareMinute` `#OneStep` | 맨얼굴 클로즈업 / 흡수되는 1분 무음 |
| **D. Half & Half** | 얼굴 절반만 발라 제형 차이를 직접 비교 | `#HalfAndHalf` `#TextureTest` | 좌우 대비 / 제형 근접 / 측면광 |

**컨셉 A — 상세 (메인)**

- **콘셉트**: 피부 타입이 정반대인 두 사람이 한 병을 나눠 쓰는 아침
- **스토리 구성**: 병을 건네는 손 → 각자 피부 선언 → 제형 근접 → 흡수 무음 → 같은 조명 두 얼굴
- **Hook (0–2초)**: "She's dry. I'm oily. One bottle."
- **연출 가이드**:
  - 병을 건네는 손 클로즈업으로 오프닝, 얼굴 없이 손만
  - 각자 자기 피부를 한마디로 선언. "I'm dry." / "I'm oily." 그 이상 설명하지 않음
  - 제형이 손등에 떨어지고 퍼지는 근접 컷, 자르지 않고 한 번에
  - 같은 조명에서 두 얼굴. **같아 보이게 만들지 않음**
  - CTA — 나와 피부 타입이 반대인 친구 태그

**컨셉 B — 상세**

- **콘셉트**: 이미 쓰고 있는 아침 루틴 안에서 이 제품이 지나가는 자리
- **스토리 구성**: 루틴 빠른 전개 → 이 제품 차례에서 감속 → 메이크업 완성 피부
- **Hook**: "The step nobody films." / "I have 40 seconds before I leave."
- **연출 가이드**: 순서를 사용법처럼 말하지 않고 "내 루틴"으로 말함 / 지속력·밀림 방지 언급 금지 / CTA는 "이 자리에 뭘 쓰는지 댓글로"

**컨셉 C — 상세**

- **콘셉트**: 아무것도 안 바른 얼굴에서 시작해 딱 한 병만
- **스토리 구성**: 맨얼굴 클로즈업 → 한 방울 → 1분 무음 → 측면광 피부 표면
- **Hook**: "Bare face. One drop. One minute." / "No filter. No primer. No ring light."
- **연출 가이드**: 멘트 없이 끝냄 / 무문구 엔딩

**컨셉 D — 상세**

- **콘셉트**: 얼굴 절반만 발라 제형과 마무리 차이를 직관적으로 비교
- **스토리 구성**: 절반 도포 → 좌우 근접 비교 → 측면광 확인
- **Hook**: "Only half my face." / "Can you tell which side?"
- **연출 가이드**: 효능 비교가 아니라 **제형·마무리 비교**로만 / 비포애프터 대비 연출 금지 / 경쟁 제품과 비교 금지

**캐스팅 기준**

| 기준 | 적용 |
| --- | --- |
| 자기 피부를 한 문장으로 말할 수 있는 사람 | 1순위 기준. "I'm dry." 를 어색하지 않게 하는 사람 |
| 건성 × 지성 페어 | 컨셉 A 핵심. 친구·룸메이트·자매 등 **실제 관계가 보이는** 조합 |
| 데일리 메이크업 사용자 | 컨셉 B |
| 선케어 루틴 보유자 | 컨셉 B. 단 사용 순서를 규칙처럼 말하게 하지 않음 |
| **쓰지 않는 기준** | 연령·성별·인종·지역·피부톤. 리뷰 데이터에 없어 "실제 구매자는 이렇다"의 근거로 쓸 수 없음. 캐스팅 다양성은 브랜드 판단으로 정하되 데이터 근거로 포장하지 않음 |

**발행 일정**

- 집중 발행 구간을 만들어 Amazon 유입 피크를 명확히 관측 가능하게 함
- W1: 컨셉별 2건씩 선발행 (총 8건) → 초기 반응 확인
- W2–W3: **주중 3일 집중 발행** (총 24건) → 세션·판매 피크 구간 형성
- W4: 성과 상위 컨셉만 추가 발행 + Spark Ads 연계
- 발행 전 최소 7일 baseline 확보 (비교 기준선)

**2) 위닝 컨셉 판정 기준**

컨셉 하나를 승자로 확정하는 조건. 아래 4개를 함께 본다.

| 기준 | 판정선 |

| --- | --- | --- |
| 조회수 / 팔로워 배수 | 조회수 ÷ 팔로워 수 | Nano·Micro 티어의 실제 효율 판정. 절대 조회수로는 안 보임 |
| ER | (좋아요+댓글+저장+공유) ÷ 조회수 | 컨셉별 몰입도 비교 |
| 저장률 | 저장 ÷ 조회수 | **이 캠페인의 핵심 중간 지표.** 제형 중심 콘텐츠는 "나중에 사야지"로 저장됨 |

**5) 비용 효율**

| 지표 | 계산 |
| --- | --- |

**아직 정하지 못한 것**

- **SKU 배정** — 리뷰가 브랜드 전체 기준이라 제품별 컨셉 배정 근거 없음
- **리뷰 인용** — 단어 단위 추출이라 리뷰를 따옴표로 인용할 수 없음. 훅은 전부 크리에이터 화법으로 작성
- **민감 피부 컨셉** — 긍정·부정이 모두 확인돼 별도 컨셉으로 만들지 않음. 진행하려면 법무 검토 선행
- **"기름지지 않다"** — 긍정 리뷰의 greasy 70건은 부정어가 붙은 표현일 가능성이 있어 메시지 근거로 쓰지 않음
- **목표 수치** — 브랜드 과거 캠페인 실적과 Amazon 데이터가 들어와야 확정 가능
